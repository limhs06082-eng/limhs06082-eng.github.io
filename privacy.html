G-Work 개인정보처리방침

시행일: 2026-10-05

1. 기본 원칙

G-Work는 사용자의 Windows 컴퓨터에 설치해 쓰는 프로그램입니다. 업무 기록과 설정은 그 컴퓨터의 G-Work 데이터 폴더에만 저장됩니다. G-Work 개발자는 서버를 운영하지 않으며, 사용자의 개인정보·업무 기록·Google 데이터를 받거나 보관하지 않습니다.

2. Google Calendar 데이터 (Google 사용자 데이터)

Google Calendar 연결은 선택 기능이며, 사용자가 설정에서 [연결하기]를 누를 때만 시작합니다.

2.1 요청하는 권한과 쓰는 곳

  • calendar.events.owned.readonly (연결할 때): 기본 캘린더의 오늘 일정(일정 이름·시작·끝·상태)을 읽어 오늘 화면에 보여 줍니다.
  • calendar.calendars.readonly (연결할 때): 연결한 계정을 표시하려고 기본 캘린더의 id(보통 이메일 주소)만 읽습니다.
  • calendar.events.owned (처음 [Google Calendar에 추가]를 누를 때 따로 요청): 사용자가 고른 업무 기한을 ([Google Calendar에 추가]는 그 기한 하나, [모든 기한 추가]는 그 업무의 기한들) 기본 캘린더에 일정으로 추가합니다. 그 밖의 일정은 만들거나 바꾸거나 지우지 않습니다.

2.2 저장

  • 읽은 일정은 화면에만 보여 주고 저장하지 않습니다.
  • 이 컴퓨터에는 연결 정보(연결한 계정 표시, 받은 권한)와 G-Work가 추가한 일정의 기록(일정 이름, 날짜, Google 일정 id — 같은 기한을 두 번 넣지 않기 위함)만 저장합니다.
  • 로그인 유지 토큰(refresh token)은 Windows 자격 증명 관리자에만 보관하고, 접근 토큰은 프로그램이 켜져 있는 동안 메모리에만 둡니다. 로그·파일에 기록하지 않습니다.

2.3 제공·전송

  • Google 데이터는 G-Work 개발자를 포함한 누구에게도 보내거나 제공하지 않습니다.
  • Google 데이터는 공문 정리·자료 만들기에 쓰는 AI 서비스로 보내지 않으며, AI 모델 학습에 쓰지 않습니다.
  • Google 데이터를 광고·판매·신용 평가 등 다른 목적에 쓰지 않습니다.

G-Work가 Google API로 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구 사항 포함)을 따릅니다.

2.4 연결 해제와 삭제

  • 설정의 [연결 해제]를 누르면 Google에 권한 취소를 요청하고, 이 컴퓨터의 토큰과 연결 정보를 지웁니다.
  • Google 계정의 서드 파티 액세스 관리에서도 언제든 권한을 취소할 수 있습니다.
  • 설정의 [G-Work 데이터 모두 삭제]는 이 컴퓨터의 G-Work 데이터를 지우며, 'Google Calendar 연결도 해제'를 고르면 Google 연결도 함께 해제합니다.

3. 공문 정리·자료 만들기 (AI 서비스)

  • 사용자가 버튼을 누를 때만, 사용자가 직접 등록한 OpenAI API 키로 공문 내용을 OpenAI에 보내 정리합니다. 보내기 전에 주민등록번호·전화번호·이메일·학생 이름 등 개인정보를 이 컴퓨터에서 가리고, 개인정보가 많은 문서는 보내지 않습니다.
  • 요청은 저장하지 않음(store: false)으로 보냅니다. Google 데이터는 이 요청에 넣지 않습니다.
  • API 키는 Windows 자격 증명 관리자에만 보관합니다.

4. 보유 기간과 파기

모든 데이터는 사용자의 컴퓨터에 있으며 사용자가 지울 때까지 남습니다. 업무별 삭제, 원본 삭제, 전체 삭제를 프로그램 안에서 할 수 있고, 프로그램을 제거할 때 데이터 삭제를 고를 수 있습니다.

G-Work Privacy Policy

Effective date: 2026-10-05

1. Overview

G-Work is a Windows desktop application installed on the user's own computer. Work records and settings are stored only in G-Work's data folder on that computer. The developer of G-Work operates no server and does not receive or keep any personal data, work records or Google user data.

2. Google Calendar data (Google user data)

Connecting Google Calendar is optional and starts only when the user clicks "Connect" in Settings.

2.1 Scopes and how they are used

  • https://www.googleapis.com/auth/calendar.events.owned.readonly (requested when connecting): reads today's events (title, start, end, status) on the user's primary calendar to show them on the Today screen.
  • https://www.googleapis.com/auth/calendar.calendars.readonly (requested when connecting): reads only the primary calendar's id (usually the e-mail address) to show which account is connected.
  • https://www.googleapis.com/auth/calendar.events.owned (requested separately the first time the user adds a deadline): creates events on the primary calendar only for the task deadlines the user explicitly chooses to add (one deadline, or all deadlines of that task). G-Work never creates, edits or deletes any other event.

2.2 Storage

  • Events read from Google Calendar are displayed only and are not stored.
  • On the user's computer G-Work stores only the connection details (account label and granted scopes) and a record of events G-Work itself created (title, date and Google event id, to avoid adding the same deadline twice).
  • The refresh token is kept only in Windows Credential Manager; the access token is kept in memory while the program runs. Tokens are never written to logs or files.

2.3 Sharing and transfer

  • Google user data is not sent or disclosed to anyone, including the developer.
  • Google user data is never sent to the AI service G-Work uses for documents, and is never used to train AI or machine-learning models.
  • Google user data is not used for advertising, sold, or used for any other purpose.

G-Work's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

2.4 Disconnecting and deletion

  • "Disconnect" in Settings asks Google to revoke the grant and deletes the tokens and connection details from the computer.
  • Users can also revoke access at any time at Google Account → Third-party access.
  • "Delete all G-Work data" in Settings removes all G-Work data and, when the user ticks the option, also disconnects Google Calendar.

3. Document processing (AI service)

Only when the user clicks a button, G-Work sends document text to OpenAI using the API key the user registered. Personal information is masked on the computer before sending, and documents with much personal information are not sent. Requests are sent with store: false. Google user data is never included.

4. Retention and deletion

All data stays on the user's computer until the user deletes it, per task or all at once, inside the program or when uninstalling.
